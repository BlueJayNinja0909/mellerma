1. Project Overview & Goals

Mellerma is an independent streetwear brand built around a core philosophy: "Not made to follow trends. Made to create our own lane. Lowkey movement. High ambition." The website serves as the brand's primary digital presence — a place to sell clothing, communicate the brand's identity, and build a community around a unified mindset.

The project involves designing and developing a complete multi-page e-commerce website from scratch using HTML, CSS, and JavaScript — no page builders, no templates. Every design decision is intentional and tied to the brand's aesthetic: dark, minimal, premium, and purposeful.

Primary Goals

01
Sell Products Online
Enable customers to browse, select a size, and purchase clothing directly through the site using PayPal. No third-party store platform — fully custom built.
02
Communicate Brand Identity
Every page should feel like the brand — dark backgrounds, gold accents, sacred imagery, editorial typography. The design itself is part of the message.
03
Build Community
Email signup, Instagram links, and brand manifesto content to attract and retain people who connect with the movement, not just the product.
04
Professional Credibility
Legal pages, secure checkout, professional copywriting, and polished UI to establish the brand as a real, trustworthy business from day one.

2. Target Audience

Mellerma is designed for a specific person — not a broad demographic. The brand speaks to young adults (16–28) who:

  • Identify with streetwear and urban culture but want something more meaningful than mainstream brands
  • Come from different backgrounds but share a mindset of ambition, faith, and self-building
  • Appreciate premium quality and unique design details (rhinestones, graphic prints, heavyweight fabric)
  • Discover brands through social media — primarily TikTok and Instagram
  • Value authenticity — they can tell when something is made with intention vs. mass-produced

User Needs

  • To quickly understand what the brand is about when they land on the site
  • To see the product clearly — multiple angles, detail shots, size information
  • To purchase easily and securely without friction
  • To feel like they're joining something, not just buying something

The palette is intentionally minimal — near-black backgrounds with gold accents create a premium, editorial feel. Deep red is used sparingly for product badges and marquee separators. Off-white for body text maintains readability without the harshness of pure white on black.

Typography

RoleFontWeight / StyleUsage
Display / Hero Bebas Neue 400 Regular Page titles, product names, hero heading, section titles. Large, condensed, impactful.
Brand / Wordmark Cinzel 900 Black Navigation logo, product names in cards, modal titles, checkout headings. Serif authority.
Editorial / Accent Cormorant Garamond 300–400, Italic Taglines, pull quotes, manifesto text, product taglines. Elegant contrast to bold display type.
Body / UI DM Sans 300–500 All body text, labels, form fields, navigation links, spec lists. Clean and highly legible.

Design Principles

  • Dark first: Near-black backgrounds on every page. The darkness gives the gold accents their impact.
  • Minimal but detailed: Simple layouts with high-detail micro elements — noise texture overlay, thin gold borders, rhinestone references in UI.
  • Editorial spacing: Generous padding and whitespace. Content breathes. Nothing feels cramped.
  • Sticky navigation: Fixed nav bar on every page with a frosted glass blur effect for depth.
  • Scroll reveals: Content fades up into view using IntersectionObserver for a polished feel.
  • Consistent iconography: The circle cross logo appears as a watermark on the homepage hero and as a subtle presence throughout.

8. Technical Stack

The entire site is built with vanilla web technologies — no frameworks, no build tools, no CMS. This was a deliberate choice to demonstrate fundamental web development skills and maintain full control over every design detail.

🌐
HTML5
Semantic structure for all 9 pages. Proper use of nav, section, article, footer elements.
🎨
CSS3
Custom properties, Grid, Flexbox, animations, IntersectionObserver-driven reveals, sticky positioning.
⚙️
JavaScript
Vanilla JS for zoom lightbox, image gallery, accordion menus, cart logic, form validation, toasts.
💳
PayPal SDK
Live PayPal Buttons integration via JS SDK. Real payment processing — no server required for PayPal.
🔐
Stripe.js
Stripe Elements loaded for future card processing. Currently inactive — server integration pending.
📦
GitHub Pages
Static site hosting via GitHub Pages. Free, reliable, deploys directly from the main branch.

External Resources

  • Google Fonts — Bebas Neue, Cinzel, Cormorant Garamond, DM Sans (loaded via CDN)
  • PayPal JS SDK — https://www.paypal.com/sdk/js (live integration)
  • Stripe.js v3 — https://js.stripe.com/v3/ (loaded but inactive)
  • All images — Self-hosted in the GitHub repo root directory

9. Features & Functionality

Navigation

  • Fixed navigation bar on all pages with backdrop blur
  • Active state highlighting on current page
  • Responsive — nav links hidden on mobile, replaced with context-appropriate button
  • Smooth scroll to sections on same-page anchor links

Product Gallery & Zoom

  • Sticky image gallery on product pages — stays in view while scrolling specs
  • 4-thumbnail strip — click any thumbnail to swap main image with preload to prevent blackout
  • Click main image → full-screen zoom lightbox opens
  • Click in lightbox → zooms in 3× at the exact click point
  • Move mouse → image pans to follow cursor (container-relative tracking to prevent edge-lock)
  • Scroll wheel → smooth zoom level adjustment (1× to 3.5×)
  • Minimap navigator → thumbnail in corner with gold box showing current viewport position
  • ESC key or click outside → closes lightbox

Checkout

  • Size selection on product page passed to checkout via URL parameter
  • Country selector dynamically updates shipping cost display
  • Three payment method tabs: Card, PayPal, Apple/Google Pay
  • PayPal Buttons SDK — live, real payment capture
  • Stripe card fields — UI complete, server integration pending for live card processing
  • Form validation before submission
  • Order confirmed success state with customer email display

Scroll Reveals

  • IntersectionObserver watches all .reveal elements
  • Fades in + translates up when element enters viewport
  • Used on all major content sections across the site

Legal Pages

  • Tab-based navigation (Copyright, Privacy, Terms, Returns)
  • Hash-based deep linking (e.g. legal.html#privacy)
  • Full content for all four policy sections
  • Linked from footer of every page and from checkout small print

10. Development Timeline

Phase 1
Planning
Defined brand identity, site structure, and content requirements. Created wireframe sketches for all major pages. Established color palette, typography choices, and design principles. Wrote content for all pages.
Phase 2
Base Build
Built homepage, shop page, and about page. Established shared CSS variables, nav component, footer component, and overall dark-theme design system. Set up GitHub Pages hosting and repo structure.
Phase 3
Product Pages
Built both product detail pages with sticky gallery, spec lists, size selectors, accordion menus, and purchase flow. Implemented image preloading to fix thumbnail blackout bug. Corrected all image filenames to match GitHub repo.
Phase 4
Zoom Feature
Designed and implemented the zoom lightbox system. First version used transform-origin on the image element — caused edge-lock glitch. Rewrote to track mouse on the container element instead. Added minimap navigator with position dot. Fixed syntax error from orphaned code block.
Phase 5
Checkout & Payments
Built dedicated checkout pages for each product. Integrated PayPal JS SDK with live Client ID for real payment capture. Integrated Stripe Elements UI for future card processing. Built order confirmation success state.
Phase 6
Legal & Polish
Created legal.html with four full policy sections. Added legal links to all page footers. Updated all dates to 2026. Fixed footer link visibility (color contrast). Final cross-browser testing and bug fixes.
Phase 7
Launch Prep
Currently in progress. Remaining: switch PayPal from Sandbox to Live mode, add remaining product content, complete Stripe server integration for card payments, final mobile responsiveness review.

11. Testing & QA

Browser Testing

  • Google Chrome (primary development browser) — fully tested
  • Microsoft Edge — layout verified, all features functional
  • Firefox — tested, minor font rendering differences, no functional issues
  • Mobile Chrome (Android) — responsive layout verified

Functionality Testing

  • All nav links verified across all 9 pages
  • Thumbnail image switching — tested all four images on both product pages, no blackout
  • Zoom lightbox — click to open, click to zoom, mouse pan, scroll zoom, ESC to close, minimap updates
  • Size selector — selection state, URL parameter passing to checkout
  • PayPal button — renders correctly in Sandbox mode, full order flow tested
  • Accordion menus — open/close, only one open at a time
  • Scroll reveals — trigger correctly on scroll, no double-fire
  • Footer legal links — verified on all pages
  • Email subscribe form — validation for missing/invalid email

Known Limitations

  • Card payments (Stripe) are UI-only — server backend required for live processing
  • PayPal currently in Sandbox mode — live switch needed before public launch
  • No email backend — subscribe form shows a toast notification but does not send data to a server
  • No inventory management — stock is not tracked, orders are not stored in a database
